# Scott Portfolio — Website Source

Portfolio of Lê Duy Thông (Scott).

## Open the website
Extract this ZIP, then open index.html in your browser.
For a local server, run `python -m http.server 8000` in the extracted folder
and visit http://localhost:8000.

## Edit
- index.html: content, images, links, and section structure
- design.css: active design, responsive layouts, glass styling, and animations
- app.js: navigation, scroll effects, and image previews
- assets/: photographs, certificates, project screenshots, and icons
- style.css: retained earlier stylesheet (not loaded by the current page)

No build step or package installation is required.
Google Fonts requires an internet connection; system fonts are used as a fallback.
To host with GitHub Pages, upload the contents to the repository root.
